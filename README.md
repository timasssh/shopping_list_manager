# Gerenciador de Lista de Compras

Este projeto consiste em um site simples desenvolvido com **HTML, CSS e JavaScript**, cujo objetivo principal é servir como prática para o uso do **Git**, com foco especial no conceito de **branches**.

A aplicação funciona como um gerenciador de lista de compras, permitindo visualizar itens já adicionados e cadastrar novos itens por meio de um formulário.

---

## 🎯 Objetivo do Projeto

O principal objetivo deste projeto **não é a complexidade da aplicação**, mas sim:

- Praticar versionamento de código com **Git**
- Aprender e consolidar o uso de **branches**
- Trabalhar com fluxo de desenvolvimento (criação, alteração e merge de branches)
- Manter um histórico de commits organizado

---

## 🛒 Funcionalidades

- Visualização da lista de compras
- Adição de novos itens por meio de um formulário
- Separação de telas (lista e formulário)
- Manipulação básica do DOM com JavaScript

---

## 🧰 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git

---
